Quick Start Guide

Get up and running in minutes

Blueprint Example
The simplest way to serialize any struct to JSON in Blueprint:
Blueprint Nodes:
1. Create your USTRUCT variable
2. Connect to "Struct to JSON String" node
3. Get JSON string output
That's it!
C++ Example
Quick C++ serialization example: 
// Define your struct
USTRUCT()
struct FMyData
{
    GENERATED_BODY()
    
    UPROPERTY()
    FString Name;
    
    UPROPERTY()
    int32 Score;
};

// Serialize to JSON
FMyData Data;
Data.Name = TEXT("Player");
Data.Score = 100;

FString JsonString;
FJsonObjectConverter::UStructToJsonObjectString(Data, JsonString);

Core JSON Operations

Fundamental JSON object creation and manipulation

Create Empty JSON Object
Blueprint
Creates a new, empty JSON object that can be populated with data.
Returns UStructForgeJsonObject*
Category StructForge|Core
C++ Example:
UStructForgeJsonObject* JsonObj = UStructForgeBlueprintLibrary::CreateJsonObject();
Parse JSON String
Blueprint
Parses a JSON string and creates a JSON object from it.
Parameter Type Description
JsonString FString The JSON string to parse
OutJsonObject UStructForgeJsonObject*& The resulting JSON object
C++ Example:
FString JsonString = TEXT("{\"name\":\"John\",\"age\":30}");
UStructForgeJsonObject* JsonObj = nullptr;
bool bSuccess = UStructForgeBlueprintLibrary::ParseJsonString(JsonString, JsonObj);
JSON Object to String
Blueprint
Converts a JSON object to its string representation.
Parameter Type Description
JsonObject UStructForgeJsonObject* The JSON object to convert
bPrettyPrint bool Format with indentation
C++ Example:
FString JsonString = UStructForgeBlueprintLibrary::JsonObjectToString(JsonObj, true);

Blueprint
Retrieves a string value from a JSON object by key.
Parameter Type Description

DefaultValue FString Value if key not found
bFound bool& Was the key found?
C++ Example:

Struct Serialization

Serialize any USTRUCT to/from JSON

Struct to JSON String (Generic)
Blueprint
The power of STRUCTFORGE - serialize ANY USTRUCT to JSON without modification. In Blueprint, this node accepts wildcard struct pins!
C++ Example:
// Define any struct
USTRUCT(BlueprintType)
struct FMyCustomData
{
    GENERATED_BODY()
    
    UPROPERTY()
    FString Name;
    
    UPROPERTY()
    TArray<int32> Values;
    
    UPROPERTY()
    FVector Position;
};

// Serialize without any setup!
FMyCustomData Data;
Data.Name = TEXT("Test");
Data.Position = FVector(100, 200, 300);

FString JsonString;
FJsonObjectConverter::UStructToJsonObjectString(Data, JsonString, 0, 0, 0, nullptr, true);

Metadata-Based Serialization

Control JSON serialization with UPROPERTY metadata

Custom Field Names & Exclusion
C++
Use metadata to customize how your structs are serialized to JSON.
Example:
USTRUCT()
struct FCustomSerializedStruct
{
    GENERATED_BODY()
    
    // This field will be serialized as "player_name" in JSON
    UPROPERTY(meta=(JsonFieldName="player_name"))
    FString PlayerName;
    
    // This field will be excluded from JSON
    UPROPERTY(meta=(JsonSerialize="false"))
    FString InternalData;
    
    // Normal serialization
    UPROPERTY()
    int32 Score;
};

// Use metadata-aware serialization
FString JsonString;
UStructForgeHandler::SerializeUStructToJsonObjectStringWithMetadata(
    FCustomSerializedStruct::StaticStruct(),
    &MyStruct,
    JsonString,
    true
);
Field Mapping Selective Serialization
