⭐ Struct to JSON String (Generic)

THE POWER OF STRUCTFORGE! Serialize ANY USTRUCT to JSON without modification. In Blueprint, this node accepts wildcard struct pins!
f

Struct (Wildcard)
Pretty Print
JSON String
Success
C++ Example
// Define ANY struct
USTRUCT()
struct FMyGameData
{
    GENERATED_BODY()
    
    UPROPERTY()
    FString PlayerName;
    
    UPROPERTY()
    int32 Score;
    
    UPROPERTY()
    TArray Inventory;
};

// Serialize it without any setup!
FMyGameData GameData;
GameData.PlayerName = TEXT("Hero");
GameData.Score = 5000;
GameData.Inventory = {TEXT("Sword"), TEXT("Shield")};

FString JsonString;
bool bSuccess = FJsonObjectConverter::UStructToJsonObjectString(
    GameData, JsonString, 0, 0, 0, nullptr, true);

Metadata-Based Serialization
SerializeUStructToJsonObjectStringWithMetadata
Advanced C++ Only
Control JSON serialization using UPROPERTY metadata tags.
C++ Example
USTRUCT()
struct FCustomSerializedStruct
{
    GENERATED_BODY()
    
    // Custom JSON field name
    UPROPERTY(meta=(JsonFieldName="player_name"))
    FString PlayerName;
    
    // Exclude from JSON
    UPROPERTY(meta=(JsonSerialize="false"))
    FString InternalData;
    
    UPROPERTY()
    int32 Score;
};

// Use metadata-aware serialization
FString JsonString;
UStructForgeHandler::SerializeUStructToJsonObjectStringWithMetadata(
    FCustomSerializedStruct::StaticStruct(),
    &MyStruct,
    JsonString,
    true
);
